AURORA NOEL — Windows 免安装版
================================

1. 解压整个文件夹（不要在压缩包里直接运行）。
2. 双击「Start Aurora Noel.bat」。
3. 浏览器会自动打开 http://127.0.0.1:4173/
4. 点击页面右上角的「启用手势」，允许摄像头访问。
5. 使用结束后，关闭黑色命令行窗口即可停止本地服务。

说明
----
- 不需要安装 Node.js、Python 或任何开发环境。
- 需要 Windows 10 / 11，以及 Edge、Chrome 等现代浏览器。
- 摄像头只在本地浏览器中处理，不会上传。
- 页面必须通过 127.0.0.1 打开，不能直接双击 site\index.html，否则摄像头和 WebAssembly 会被浏览器安全策略拦截。
- 如果 4173 端口被占用，脚本会自动尝试 4174–4185，并在窗口中显示实际地址。
- 如果 Windows 提示文件来自网络，请选择允许运行；或右键压缩包 → 属性 → 解除锁定。
- 如果黑色窗口提示找不到 site\index.html，请确认解压后 server.ps1 和 site 文件夹在同一级目录。
